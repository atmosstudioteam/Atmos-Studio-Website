# Atmos Studio Website

Official standalone redesign repository for Atmos Studio.

The original `Atmos-Studio` repository is not modified by this project.

## Content policy

The website intentionally preserves the original Atmos Studio website content and page structure:

- `index.html` — Home
- `builds.html` — Builds
- `privacy-policy.html` — Privacy Policy
- `terms-of-use.html` — Terms of Use

Page content is loaded from the existing `Atmos-Studio` GitHub Pages source and displayed with the redesign stylesheet from this repository. This keeps the text, section order, links, EN/RU content, project information, release model, and legal documents identical to the original source while allowing the visual design to be changed independently.

## Design files

- `styles.css` — base visual styles
- `source-overrides.css` — redesign applied over the original page structure
- `page-loader.js` — loads the original page content and original behavior without editing the source repository

## Deployment

GitHub Pages can publish this repository directly from the `main` branch root. No build step is required.
